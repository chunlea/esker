# Groups 8, 9, 10 and 11 of r1's wire-108 baseline, measured together because they are all
# questions about what an aggregate answers.
#
# ## THINGS REASONING WOULD GET WRONG
#
#   * **A `real` sums to a `real` and averages to a `double precision`.** Not a widening rule and
#     not a narrowing one — `pg_aggregate` says why: `sum(float4)`'s transition type is `float4`
#     and `avg(float4)`'s is `float8[]`, so the sum accumulates in single precision and the average
#     widens *before* the division. The same sentence `min(time)` and `sum(time)` make: the result
#     is per (aggregate, type) and not per type.
#
#   * **`min` and `max` do not exist over `tsvector` or `tsquery`** — `42883` — and the list is a
#     census rather than a growing collection of surprises. `pg_proc` holds twenty-five
#     one-argument `min`s:
#
#         anyarray, anyenum, bigint, bytea, character, date, double precision, inet, integer,
#         interval, money, numeric, oid, oid8, pg_lsn, real, record, smallint, text, tid,
#         timestamp, timestamptz, time, timetz, xid8
#
#     Everything else is `42883`, `uuid`, `boolean` and `jsonb` included — each checked directly
#     as well, because a list read off a catalog is a claim until one of its members is asked.
#
#   * **`string_agg` has exactly two overloads**, `(text,text)` and `(bytea,bytea)`, so a `real`
#     first argument is `42883` rather than a coercion. Its **NULL delimiter is an empty
#     separator**, not a NULL answer: `string_agg(t, NULL)` over `a` and `b` is `ab`. Over no rows
#     it is NULL. `ORDER BY` inside the parentheses orders the join; `DISTINCT` folds first.
#
#   * **An aggregate over a *domain* column answers the domain's own array.**
#     `information_schema.tables.table_name` is the domain `sql_identifier` (13361, `typtype = d`,
#     base `name`), and `array_agg` of it is `_sql_identifier` (13360) — not `_name` (1003). The
#     two oids are assigned when `information_schema` is created rather than fixed by catalog
#     version, which is why they are recorded beside the query that read them. **`min` of the same
#     column is a plain `text`**: the domain decays to its base's rule, and `name`'s rule is to
#     borrow `text`'s.
#
