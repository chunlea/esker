# **The comparison matrix, third pairing** — a **column** against a **typed literal** —
# PostgreSQL 19beta1, 2026-09-10.
#
# `tests/captures/pg19_comparison_matrix.txt` measured the same 53 type spellings twice, over two
# columns and over two literals, and this node now agrees with both. Neither reaches the arms a
# **mixed** pair takes: `exec::query::reconcile` matches `(Ordinal, Literal)` before either family
# check and calls `retype`, whose first gate is `Literal::comparable_with` — and that ends in
# `Datum::fits`, the **assignment** rule. It is the same shape as the cast arms, which answered
# `'x'::text = '<a/>'::xml` until `debts-v1.1.md` #43's second mechanism closed on 2026-09-10.
#
# So this is the third of the three pairings and the last one unmeasured. `void` is the one
# spelling that cannot be a column (measured), so it appears on the literal side only:
# 52 columns x 53 literals = 2756 rows.
#
# The second field is `boolean` where PostgreSQL answers and `!<message>` where it refuses. The
# position suffix the literal-form capture carries (`at character 21`) is not here: these
# statements are not those statements and the offsets would not transfer.
#
