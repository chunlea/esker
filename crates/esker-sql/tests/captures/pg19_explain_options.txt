# **`EXPLAIN (...)`** — the option list, its five errors, and the four documents `FORMAT` chooses
# between, as PostgreSQL 19beta1 answers them.
#
# Run 100's board carries four tests behind this: `explain_test.rb`'s three option-list cases and
# `connection_test.rb`'s `test_statement_key_is_logged`. The first three assert only that the
# statement was accepted; the fourth reads the answer back **through the column's type OID**, which
# is why the `\gdesc` block below is the decisive part of this capture and not a detail.
#
# Taken 2026-09-05 against 127.0.0.1:55432 (user/db `esker`), `\set VERBOSITY verbose`, everything
# inside one `BEGIN … ROLLBACK` with **every** probe in its own `SAVEPOINT` — including the ones
# expected to succeed, which is the rule that stopped an unexpected error from swallowing the rest
# of the file. The counts after the rollback prove nothing persisted.
#
# WHAT REASONING WOULD HAVE GOT WRONG
#
#   * **`BUFFERS` does not require `ANALYZE`** on 19 — it reports planning buffers. `TIMING`, `WAL`
#     and `SERIALIZE` do, and they are checked *after* the whole list is read, so
#     `(TIMING, ANALYZE)` is legal and `(TIMING)` is not.
#   * **An unrecognized option NAME is `42601` and an unrecognized option VALUE is `22023`.** Two
#     classes, one statement, and no family resemblance to guess from.
#   * **`FORMAT YAML` declares `text`, not some yaml type.** `FORMAT XML` declares `xml`.
#   * **`FORMAT` outside the parentheses is a syntax error.** `sqlparser` parses it for the
#     dialects where it is not, so accepting it here would answer where a real server raises.
#   * A structured document is **one row**, not one row per line.
#   * A non-`public` relation is named **bare** without `VERBOSE` and qualified with it — which is
#     what found the NUL byte this node had been printing in that position (`tests/alias.rs`).
#

# 4. EVERY OPTION, ACCEPTED OR NOT (fixture `b4_t (id int8 PRIMARY KEY, name text, amount int8)`)

#
#   accepted with no ANALYZE:  ANALYZE VERBOSE COSTS BUFFERS SETTINGS SUMMARY MEMORY GENERIC_PLAN FORMAT

#   EXPLAIN (SERIALIZE) …         ERROR:  22023: EXPLAIN option SERIALIZE requires ANALYZE
#   EXPLAIN (TIMING, ANALYZE) …   accepted -- the check is after the whole list

#   EXPLAIN (NOSUCHOPTION) …      ERROR:  42601: unrecognized EXPLAIN option "nosuchoption"
#                                 LOCATION:  ParseExplainOptionList, explain_state.c:168
#   EXPLAIN (FORMAT NOSUCHFORMAT) ERROR:  22023: unrecognized value for EXPLAIN option "format": "nosuchformat"

#   EXPLAIN () …                  ERROR:  42601: syntax error at or near ")"     -- the grammar, not the loop
#
#   The option name is DOWNCASED in every message but the "requires ANALYZE" one, which uppercases
#   it -- PostgreSQL's grammar folds the identifier and that sentence writes the flag's own name.
#
#   Booleans read: no argument at all (true), TRUE/FALSE, on/off, 1/0. `EXPLAIN (analyze 1)` and
#   `EXPLAIN (ANALYZE on, TIMING off)` are both accepted. A second `ANALYZE` wins rather than
#   raising: `EXPLAIN (ANALYZE, ANALYZE)` is accepted.

# 7. WHAT WAS NOT TAKEN, and is a gap rather than a divergence
# ────────────────────────────────────────────────────────────────────────────────────────────────
#
#   * `EXPLAIN EXECUTE <name>(args)` — accepted there (protocol-level and SQL-level prepared
#     statements share one namespace); `26000 prepared statement "x" does not exist` for a name
#     nobody prepared. This node has no `EXECUTE` at all, so `connection_test.rb`'s
#     `test_statement_key_is_logged` still fails on that half. Sized separately.
#   * `EXPLAIN ANALYZE INSERT/UPDATE/DELETE` — PostgreSQL **runs** it (the probe here failed on a
#     not-null constraint, which is the proof it ran). Still `0A000` by name here, and still a
#     listed divergence in `tests/routing.rs`.
#   * `EXPLAIN CREATE TABLE t (a int8)` — a syntax error on 19 (`EXPLAIN` takes only the
#     row-producing statements plus `CREATE TABLE AS`/`DECLARE`/`EXECUTE`). Accepted here, which is
#     a divergence older than this unit.
