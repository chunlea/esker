# The order a real PostgreSQL 19beta1 sorts values in -- what an index key encoding has to
# reproduce with plain byte comparison (docs/plans/phase-6a.md §6, §7).
#
#   type <tab> value <tab> value <tab> ...      ascending, as PostgreSQL returned them
#
# Values are written the way PostgreSQL prints them, so the test reads each one back with
# `Datum::from_text` before encoding it. Values that PostgreSQL considers *equal* may appear in
# either order here -- `0` and `-0` do -- so the test asserts the encoding is non-decreasing and
# that tied values encode to identical bytes, which is the stronger property anyway: a unique
# index would admit both copies otherwise.
#
# `citext` is here for the same reason and captured the same way, with one extra step: its key is
# the **folded** value, so the fixture is `ORDER BY lower(v::text) COLLATE "C"` — which is what this
# node's key encoding is, written as SQL. Under the container's own `en_US.utf8` a citext sorts `~`
# second, and byte order does not; that is the *same* recorded divergence `text` has below and not
# a second one.
#
# `text` was sorted with `COLLATE "C"`, deliberately. The container's database collation is
# `en_US.utf8`, under which `a` sorts before `B`; ours is byte order, under which it does not.
# That is a recorded divergence, not an oversight -- see `crate::row` for why a pure-Rust project
# with no ICU has byte ordering as its only honest option, and why it is declared rather than
# stumbled into.

# `character(n)` can live in an index key. Padded values compare as bytes, and byte comparison over
# them *is* PostgreSQL's blank-insensitive comparison; the first value is three spaces, which is
# what the empty string becomes. Sorted with `COLLATE "C"` for the reason `text` is.

# The four array types. Three rules in these rows and each is measured: **a NULL element sorts
# above every value** (`{1,NULL}` after `{1,2,3}`), a **prefix sorts first** (`{1,2}` before
# `{1,2,3}`, and `{1,2,3}` before the four elements of `{{1,2},{3,4}}`), and the **lower bound is
# the last tiebreak** — `[0:1]={1,2}` and `{1,2}` have the same elements and the same shape and
# are two values, ordered by where their subscripts start.
