# **A stored `regclass` column** — against PostgreSQL 19beta1.
#
# `debts-v1.1.md` #35: the row holds the oid and nothing else, and the name is put back when the
# value is printed.
#
#   statement <tab> types <tab> rows      the result, and the types `\gdesc` declared for it
#   statement <tab> <tab> -               a command with no result set, only a tag
#   statement <tab> !SQLSTATE message     PostgreSQL refused it; DETAIL and HINT follow
#
# THINGS REASONING WOULD GET WRONG
#
#   * **`RENAME` changes what an already-stored value prints**, with no rewrite and no
#     reconciliation — that is the whole reason the name cannot be in the row.
#   * **Dropping the relation leaves the number**: not NULL, not an error, the digits.
#   * **`'nosuchrel'::regclass` fails at the cast**, before a row is written.
#
# Measured in `tests/captures/pg19_stored_regclass.txt`.
