# THINGS REASONING WOULD GET WRONG
#
#   * **`START` holds in the transaction that made the sequence, before anything is drawn and after**: `last_value` is
#     `7` with `is_called` false, and `nextval` answers `7` and then `8`.
#   * **A transaction that makes a sequence and draws from it commits**, and the next value carries on — `7`, `COMMIT`,
#     `8` — in a block and in a `DO` block alike.
#   * **A `REPEATABLE READ` block that draws and then drops what it drew from commits**, whether it drops the sequence,
#     the table that owns it, or the column.
#   * **`TRUNCATE … RESTART IDENTITY` goes back to the sequence's `START`**: `50`, not `1`.
#   * **A dropped sequence's numbers go with it** — one made again under the same name starts at `1` — **and a
#     rolled-back drop keeps them**: the next is `2`.
#
