#
# THINGS REASONING WOULD GET WRONG
#
#   * **`typlen` is 64 and positive**: `name` is the one string type that is fixed width, and it
#     takes no typmod — `'x'::name(10)` is `42601`.
#   * **It truncates at 63**, not 64: one byte is the terminator. By *bytes*, and never through
#     the middle of a character — `repeat('é',64)::name` is 31 characters and 62 octets.
#   * **Its collation is C**, so a `name` column sorts in byte order and every capital comes
#     before every lower-case letter. That is not what a `text` column of the same values does.
#   * Everything it produces is `text`: `name || text`, `upper(name)`, `name::text`.
#
