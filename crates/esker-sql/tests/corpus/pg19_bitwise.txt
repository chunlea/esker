# Captured in one session inside `BEGIN … ROLLBACK`. `connection_test.rb` builds an advisory-lock
# key as `(a::bigint << 32) | b::bigint`, which is the first row.
#
# THINGS REASONING WOULD GET WRONG
#
#   * **A shift keeps its LEFT operand's type** and the right one is always an `integer`:
#     `1::int2 << 4` is `smallint`. The other four take the wider of the two operands.
#   * **A shift count is taken modulo the width.** `1::int4 << 32` is **1**, not 0, and
#     `1::int8 << 64` is 1; `1::int4 << -1` is `-2147483648`, which is `1 << 31`. Nothing
#     overflows and nothing is refused — the count wraps, which is the hardware showing through.
#   * **`>>` is arithmetic**: `(-1) >> 1` is `-1`, not a large positive number.
#   * **`&` binds tighter than `|`**, and `<<` tighter than both: `2 | 3 & 1` is `1` and
#     `1 << 2 | 1` is `5`.
#   * Two unknown literals are **`42725 operator is not unique`**, not the `42883` a wrong type
#     gets: every integer width offers a candidate and none of them wins.
