# **`<op> ANY (array)` and `<op> ALL (array)`**, measured shape by shape on PostgreSQL 19beta1.
#
# `docs/plans/debts-v1.1.md` #21 said this node has no `ALL` quantifier. It has one — for a
# **subquery** on the right, where `SubqueryKind::Quantified { op, all }` takes all six comparison
# operators — and `exec::subquery::quantified` is exactly the three-valued rule the rows below
# measure. What is missing is the *array* form for everything but `= ANY`, which `parse::lower`
# refuses by name (`0A000 ALL over an array`, `0A000 the quantifier <op> ANY`).
#
# **The rule, read off the rows and not asserted here.** A quantified comparison is a three-valued
# conjunction (`ALL`) or disjunction (`ANY`) over the element comparisons:
#
#   * an **empty** array settles it with no comparison at all — `ALL` is `true` and `ANY` is
#     `false`, and that holds even when the *operand* is NULL: `NULL = ALL (ARRAY[]::integer[])` is
#     `t`, because nothing is ever compared;
#   * one decisive element settles it past any NULLs — `1 = ALL (ARRAY[2, NULL])` is `f` and
#     `1 = ANY (ARRAY[1, NULL])` is `t`;
#   * otherwise a NULL leaves it **unknown** — `1 = ALL (ARRAY[1, NULL])` is NULL, and so is
#     `1 <> ALL (ARRAY[2, NULL])`;
#   * a NULL operand against a non-empty array is unknown for both.
#
# Two refusals, each measured rather than invented: a **non-array** right side is
# `42809 op ANY/ALL (array) requires array on right side`, and an element type with no operator is
# `42883 operator does not exist: integer = text` with PostgreSQL's own DETAIL and HINT.
#
# **`NOT IN` and `<> ALL` print identically.** `pg_get_expr` gives `(c1 <> ALL (ARRAY[1, 2]))` for
# both spellings, which is why the deparser rows are here and not in `pg19_deparse_parens.txt`:
# that file could measure the printed form and not the value, and #21 was a *language* gap behind
# a printer that was already right (ADR 0090's read-back guard kept the written text instead).
# The text elements carry their coercion — `(t <> ALL (ARRAY['a'::text, 'b'::text]))` — and an
# index over one keeps the shape's own pair, `(((c1 <> ALL (ARRAY[1, 2]))))` in `pg_get_indexdef`.
#
# The generated columns are **inserted into and read back** in the same file, so the value is
# asserted beside the deparse: a printed form that does not read back computes the wrong value, and
# only the rows can say which.
#
# **The nested-array probe is guarded by a savepoint**, and parity rule 3 is why: this node
# refuses it (see `tests/all_quantifier.rs`'s one declared divergence) and a refusal inside a
# `BEGIN` aborts the transaction, so every statement after it came back `25P02` and 40 rows of this
# file were counted as swallowed rather than compared. The harness reports that as a rule-3
# failure — a declared divergence may not swallow the file — which is exactly what it is for.
#
