# What a real PostgreSQL 19beta1 does with a **correlated subquery** -- one that names a column of
# the row outside it, phase 12 unit 4 (`docs/plans/phase-12-subquery.md`). Captured before a line of
# the implementation, in ONE session inside `BEGIN ... ROLLBACK` with `ON_ERROR_ROLLBACK on`, so the
# shared oracle is left exactly as it was found.
#
#   statement <tab> types <tab> rows      the result, and the types `\gdesc` declared for it
#   statement <tab> <tab> -               a command with no result set, only a tag
#   statement <tab> !SQLSTATE message     PostgreSQL refused it; DETAIL and HINT follow
#
# THE ONE THAT MATTERS MOST IS ABOUT NAMES, NOT ROWS:
#
#   **the inner scope shadows the outer, and it is silent when it does.**
#
#       SELECT id FROM co_a a WHERE EXISTS (SELECT 1 FROM co_b b WHERE b.a_id = id)
#
#   returns **no rows**. `id` is unqualified and `co_b` has an `id` of its own, so the condition is
#   `b.a_id = b.id` and the query is not correlated at all. The same statement with `a.id` returns
#   two rows. There is no warning and no error: a resolution rule that looked outward first, or
#   that looked outward when the inner column "did not seem to be meant", would answer a different
#   question and say nothing. Three lines below pin it from three directions -- `b.n = n`,
#   `n = a.n`, and `id = 1`.
#
# AND THREE MORE:
#
#   * a correlated **scalar** subquery is `21000` when it returns two rows **for some row**, so the
#     same statement is fine over one fixture and an error over another;
#   * an outer reference works from a subquery with **no `FROM` at all** (`SELECT (SELECT a.id)
#     FROM co_a a`), which is the smallest correlated query there is;
#   * correlation reaches **two levels out**: an innermost query can name both the middle table and
#     the outermost one, which is why an outer reference has to carry how far it reaches.
#
# The errors keep the shapes they already had: `42703 column b.nope does not exist` for an inner
# name, `42703 column a.nope does not exist` for an outer one, and `42P01 missing FROM-clause entry
# for table "z"` for a qualifier no level has.
