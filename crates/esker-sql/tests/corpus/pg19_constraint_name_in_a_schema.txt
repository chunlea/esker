# A constraint on a table in a schema other than `public` — its name in `pg_constraint`, what
# `VALIDATE`, `DROP` and `ADD CONSTRAINT` find and refuse by it, and how each sentence spells the
# constraint and its relation — as a real PostgreSQL 19beta1 answers it.
#
# Captured 2026-09-13 by lane s2-plpgsql with `sesscap.py` (`esker-coord/s2-cnames.stmts`), found
# while capturing `pg19_regnamespace.txt`: its census `UPDATE` selects a foreign key by `conname` in a
# schema. One session inside `BEGIN … ROLLBACK`, every refusal in its own `SAVEPOINT` / `ROLLBACK TO`,
# in a schema of its own; the last line proves it left nothing behind. The `\gdesc` pass runs on a
# connection of its own, where that schema does not exist, so a statement naming it has an empty
# declared-types column.
#
#!escaped
#
#   statement <tab> types <tab> rows      the result, and the types `\gdesc` declared for it
#   statement <tab> <tab> -               a command with no result set, only a tag
#   statement <tab> !SQLSTATE message     PostgreSQL refused it; DETAIL and HINT follow
#
# THINGS REASONING WOULD GET WRONG
#
#   * **Every constraint's name is bare, however it was named**: `s2cn.c`'s primary key is `c_pkey`,
#     its derived foreign key `c_p_fkey`, its `NOT NULL`s `c_id_not_null` and `c_q_not_null`. The
#     schema is `connamespace`, never part of `conname`.
#   * **A constraint sentence names its relation bare** — `of relation "c"`, `for relation "c"`,
#     `new row for relation "c"`, `on table "c"` — but **the `2BP01` dependency sentence qualifies
#     every relation and no constraint**: `constraint p_pkey on table s2cn.p`, `depends on index
#     s2cn.p_pkey`.
#   * **A `UNIQUE` constraint's name collides as a relation**: adding `c_u_key` again is
#     `42P07 relation "c_u_key" already exists`, not `42710` — the name is its index's.
#   * **Dropping the primary key keeps its column's `NOT NULL`**: `c_id_not_null` outlives `c_pkey`.
#   * **A table `CHECK` over one column is named for that column**: `k`'s `CHECK (a > 0)` is `k_a_check`,
#     the name a column constraint would get — `<table>_check` only when the expression reads no
#     column or more than one.
#
