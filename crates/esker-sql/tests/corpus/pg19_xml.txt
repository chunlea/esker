#
# **Run 74's row: 5 tests in `adapters/postgresql/xml_test.rb`.** One column, `t.xml "payload"`, a
# round trip of `<foo>bar</foo>`, an `update_all`, a NULL, and a schema dump asserting
# `t.xml "payload"`.
#
# Things reasoning would get wrong:
#
# * **`'plain text'::xml` is a value**, and so is `'<a/><b/>'`. The type takes XML *content*,
#   which may be bare text or several top-level elements — not only a document. What it refuses is
#   text that is not well formed, and the class is its own: `2200N`, where every other input
#   function raises `22P02`.
# * **Nothing is normalised**, exactly as `json` keeps what it was sent: `'  <a/>  '` keeps its
#   spaces and `'<a></a>'` does not become `'<a/>'`. The one exception is an XML **declaration**,
#   which the type's output function drops.
# * **No equality at all, and four different sentences for it** — `=`, `DISTINCT`, `ORDER BY` and
#   `CREATE INDEX` each get their own, and `min(xml)` is a fifth that none of them implies.
# * **The two line numbers in a refusal are different questions**: the `line N:` prefix is where
#   the parser stopped and the number inside names where the tag was *opened*.
