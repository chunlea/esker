# THINGS REASONING WOULD GET WRONG
#
#   * **`DROP FUNCTION` is not a no-op for a server with no user functions.** A *built-in* is
#     `2BP01 cannot drop function lower(text) because it is required by the database system`, and
#     `IF EXISTS` does **not** cover that — it covers absence, not protection. A node that
#     answered success to everything would let a schema drop `lower` and report that it had.
#   * **The message prints the function's own canonical signature, not what the user wrote.**
#     `concat(VARIADIC "any")` comes back as `concat("any")` and `convert_to(text, name)` as
#     `convert_to(text,name)` — the `VARIADIC` gone and the space after the comma gone with it.
#   * **The signature has to match, not just the name**: `lower(integer)` is `42883` where
#     `lower(text)` is `2BP01`, and `concat(text)` is `42883` because the real signature is
#     `concat("any")`.
#   * **Writing no argument list is a different statement**, not a shorthand. On a name that
#     exists once it selects that one; on an overloaded name it is `42725 … is not unique` with a
#     HINT, which `IF EXISTS` does not cover either; on a name that is nothing at all it is a
#     *different* `42883` — `could not find a function named "x"` rather than "function x() does
#     not exist", because with no argument list there is no signature to name.
#   * An unknown **schema** is still just absence: `IF EXISTS nosuch.f()` is a success.
